**Soft actor-critic** (SAC) is the default off-policy actor-critic algorithm for continuous control.
It stores every transition in a replay buffer and reuses it many times.
It also changes the objective itself, adding a reward for acting randomly.
Its on-policy counterpart is [proximal policy optimization](/notes/reinforcement-learning/ppo/).

Terms such as Q-function, replay buffer,
off-policy and entropy are defined in [useful definitions](/notes/reinforcement-learning/useful-definitions/).
We use the same Markov decision process notation as in [reward functions](/notes/reinforcement-learning/reward-functions/): states $s_t$,
actions $a_t$, rewards $R_t$, discount $\gamma$, and objective $J(\pi) = \mathbb{E}_\pi\big[\sum_t \gamma^t R_t\big]$.

## Notation

- $\pi_\theta(a \mid s)$ is the policy with parameters $\theta$.
- $Q_{\phi_1}$ and $Q_{\phi_2}$ are two independent Q-networks with parameters $\phi_1$ and $\phi_2$.
- $Q_{\bar\phi_1}$ and $Q_{\bar\phi_2}$ are their target networks,
  with slowly updated parameters $\bar\phi_1$ and $\bar\phi_2$.
- $\mathcal{D}$ is the replay buffer of transitions $(s, a, R, s', d)$, where $d = 1$ if $s'$ is terminal.
- $\alpha \gt 0$ is the **temperature**, which weights entropy against reward.
- $\mathcal{H}\big(\pi(\cdot \mid s)\big) = \mathbb{E}_{a \sim \pi}\big[-\log \pi(a \mid s)\big]$ is the policy's entropy at $s$.

## The maximum-entropy objective

Soft actor-critic changes what is being optimized.
At every step, the agent receives the reward **plus** a bonus for the entropy of its policy:

$$
J(\pi) = \mathbb{E}_{\tau \sim \pi}\left[\sum_{t=0}^{\infty} \gamma^t \Big(R_t + \alpha\, \mathcal{H}\big(\pi(\cdot \mid s_t)\big)\Big)\right].
$$

As $\alpha \to 0$ we recover the standard objective.
With $\alpha \gt 0$, the optimal policy is stochastic: it spreads probability over every action that is nearly as good as the best one,
and commits only where one action is clearly better.
This has three useful effects:

- **Exploration** is built into the objective.
  It does not decay by accident; it decays only where the Q-values justify it.
- **Robustness**: a policy that has learned several ways to succeed is less brittle when one of them fails.
- **Stable off-policy learning**: a stochastic policy smooths the targets of the critic.

The entropy bonus is in reward units.
If we multiply the rewards by $10$, the same $\alpha$ now means relatively less randomness.
This is the caveat from [reward functions](/notes/reinforcement-learning/reward-functions/): with a fixed temperature,
scaling the reward changes the optimal policy.
Automatic temperature tuning, below, removes most of this problem.

## Soft value functions

The entropy bonus enters the value functions.
Since $\mathcal{H} = \mathbb{E}_{a \sim \pi}[-\log \pi(a \mid s)]$,
the bonus can be written per sampled action as $-\alpha \log \pi(a \mid s)$.
The **soft** value functions are

$$
\begin{aligned}
V^\pi(s) &= \mathbb{E}_{a \sim \pi(\cdot \mid s)}\big[Q^\pi(s, a) - \alpha \log \pi(a \mid s)\big],\\
Q^\pi(s, a) &= \mathbb{E}_{s' \sim P}\big[R(s, a, s') + \gamma\, V^\pi(s')\big].
\end{aligned}
$$

$Q^\pi(s, a)$ contains the reward for $a$ and everything that follows, including future entropy bonuses.
It does not contain the entropy bonus of the current state, because $a$ has already been chosen.
$V^\pi(s)$ adds that bonus.
Substituting one into the other gives the **soft Bellman equation**:

$$
Q^\pi(s, a) = \mathbb{E}_{s'}\Big[R + \gamma\, \mathbb{E}_{a' \sim \pi(\cdot \mid s')}\big[Q^\pi(s', a') - \alpha \log \pi(a' \mid s')\big]\Big].
$$

Like the ordinary Bellman equation for $Q^\pi$,
it needs only a transition $(s, a, R, s')$ and a fresh sample $a'$ from the current policy.
The transition can come from any policy.
**This is what makes soft actor-critic off-policy.**

## The best policy for a given Q

Suppose $Q$ is fixed.
At a state $s$, which distribution $\pi(\cdot \mid s)$ maximizes the soft value $\mathbb{E}_{a \sim \pi}\big[Q(s, a) - \alpha \log \pi(a \mid s)\big]$?

Define the **Boltzmann distribution** of $Q$ at temperature $\alpha$:

$$
p(a \mid s) = \frac{\exp\big(Q(s, a)/\alpha\big)}{Z(s)}, \qquad Z(s) = \sum_a \exp\big(Q(s, a)/\alpha\big).
$$

$Z(s)$ is a normalizer (an integral for continuous actions).
Now expand the Kullback-Leibler divergence from $\pi$ to $p$:

$$
D_{\mathrm{KL}}\big(\pi \,\|\, p\big)
= \mathbb{E}_{a \sim \pi}\left[\log \pi(a \mid s) - \frac{Q(s, a)}{\alpha} + \log Z(s)\right].
$$

Multiply by $-\alpha$ and rearrange:

$$
\mathbb{E}_{a \sim \pi}\big[Q(s, a) - \alpha \log \pi(a \mid s)\big] = \alpha \log Z(s) - \alpha\, D_{\mathrm{KL}}\big(\pi \,\|\, p\big).
$$

The first term does not depend on $\pi$.
So maximizing the soft value is the same as minimizing the Kullback-Leibler divergence to $p$, and the maximum is $\pi = p$:

$$
\boxed{\pi^{\text{new}}(a \mid s) \propto \exp\big(Q(s, a)/\alpha\big).}
$$

At this policy, the soft value is $V(s) = \alpha \log \sum_a \exp\big(Q(s, a)/\alpha\big)$,
a smooth version of $\max_a Q(s, a)$.
As $\alpha \to 0$ it becomes exactly the max, and soft actor-critic becomes Q-learning.

Alternating these two steps - evaluate $Q^\pi$ with the soft Bellman equation,
then set $\pi \propto \exp(Q^\pi/\alpha)$ - is called **soft policy iteration**.
With tabular values, every round improves the soft objective, and it converges to the optimal maximum-entropy policy.
Soft actor-critic is an approximate version of it with neural networks and gradient steps.

## Continuous actions: fitting the policy

For continuous actions, $Z(s)$ is an intractable integral and $\exp(Q/\alpha)$ cannot be sampled directly.
Soft actor-critic restricts the policy to a parametric family (a squashed Gaussian, below) and minimizes the Kullback-Leibler divergence to the Boltzmann distribution within that family.
Dropping $\log Z(s)$, which does not depend on $\theta$, the **policy loss** is

$$
J_\pi(\theta) = \mathbb{E}_{s \sim \mathcal{D}}\Big[\mathbb{E}_{a \sim \pi_\theta(\cdot \mid s)}\big[\alpha \log \pi_\theta(a \mid s) - Q(s, a)\big]\Big].
$$

The states come from the replay buffer, but the actions are **fresh samples from the current policy**.
That is legitimate for an off-policy method.
The state distribution only decides **which states** we improve the policy at;
at each state the policy improvement step is exact.

We need the gradient of an expectation over $a \sim \pi_\theta$.
Soft actor-critic uses the **reparameterization trick**.
The network outputs a mean $\mu_\theta(s)$ and a standard deviation $\sigma_\theta(s)$.
Draw noise $\xi \sim \mathcal{N}(0, I)$ and write the action as a deterministic, differentiable function of it:

$$
u = \mu_\theta(s) + \sigma_\theta(s) \odot \xi, \qquad a = \tanh(u),
$$

where $\odot$ is the elementwise product. The noise does not depend on $\theta$, so

$$
\nabla_\theta J_\pi = \mathbb{E}_{s, \xi}\Big[\nabla_\theta \big(\alpha \log \pi_\theta(a \mid s) - Q(s, a)\big)\Big], \qquad a = \tanh\big(\mu_\theta(s) + \sigma_\theta(s) \odot \xi\big).
$$

The gradient flows through $Q$ into $a$, and from $a$ into $\theta$.
The critic tells the actor directly which way to move each action dimension.
This uses much more information per sample than the score-function gradient of [proximal policy optimization](/notes/reinforcement-learning/ppo/),
which only knows whether the sampled action was better or worse than average.

Unlike [proximal policy optimization](/notes/reinforcement-learning/ppo/),
here $\sigma_\theta(s)$ is an output of the network and depends on the state.
The policy can be precise in one state and random in another.

## The tanh squash and its log-probability

The $\tanh$ keeps every action in $(-1, 1)$.
Scale it to the environment's bounds afterwards.
But the squash changes the density, and the loss needs the density of $a$, not of $u$.

For an invertible elementwise map $a = \tanh(u)$, the change-of-variables formula gives

$$
\pi(a \mid s) = \mathcal{N}\big(u;\, \mu_\theta(s), \sigma_\theta(s)\big) \prod_{i=1}^{m} \left|\frac{da_i}{du_i}\right|^{-1},
\qquad \frac{da_i}{du_i} = 1 - \tanh^2(u_i).
$$

Taking logs:

$$
\log \pi_\theta(a \mid s) = \log \mathcal{N}\big(u;\, \mu_\theta(s), \sigma_\theta(s)\big) - \sum_{i=1}^{m} \log\big(1 - \tanh^2(u_i)\big).
$$

Near the bounds, $1 - \tanh^2(u_i)$ underflows to zero and its log is $-\infty$. The stable form is

$$
\log\big(1 - \tanh^2(u)\big) = 2\big(\log 2 - u - \operatorname{softplus}(-2u)\big),
$$

with $\operatorname{softplus}(x) = \log(1 + e^x)$.
Without this correction, the policy is rewarded for "entropy" that the squash removes: it can push $u$ to large magnitudes where all actions saturate at the bounds while reporting a wide Gaussian.

## The critic

The critic fits the soft Bellman equation.
Sample a minibatch from $\mathcal{D}$.
For each transition, sample a next action from the **current** policy,
$\tilde a' \sim \pi_\theta(\cdot \mid s')$, and form the target

$$
y = R + \gamma (1 - d)\Big(\min_{j=1,2} Q_{\bar\phi_j}(s', \tilde a') - \alpha \log \pi_\theta(\tilde a' \mid s')\Big).
$$

Each Q-network regresses onto the same target:

$$
J_Q(\phi_i) = \mathbb{E}_{(s, a, R, s', d) \sim \mathcal{D}}\Big[\big(Q_{\phi_i}(s, a) - y\big)^2\Big], \qquad i = 1, 2.
$$

Each piece of the target has a reason:

- **The fresh $\tilde a'$**: the target describes the current policy, not the one that collected the data.
  This is what lets old transitions stay useful.
- **The minimum over two critics** (clipped double Q-learning): the policy loss looks for actions where $Q$ is high,
  which includes actions where $Q$ is wrongly high.
  The minimum of two independently trained estimates counteracts this overestimation.
- **Target networks** $\bar\phi_j$: they keep the target from moving with every gradient step.
  After each update, they track the online networks by Polyak averaging,
  $\bar\phi_j \leftarrow \tau \phi_j + (1-\tau)\bar\phi_j$, with $\tau = 0.005$.
- **$(1 - d)$**: only true termination cuts off the future.
  Time-limit truncation must store $d = 0$,
  for the same reason as in [proximal policy optimization](/notes/reinforcement-learning/ppo/#episode-boundaries).

The policy loss uses the minimum of the two **online** critics:
$Q(s, a) = \min_j Q_{\phi_j}(s, a)$.

## Tuning the temperature

A fixed $\alpha$ is fragile.
Its effect depends on the reward scale, and the right amount of randomness changes during training: high at the start,
lower once the policy has found a good behavior.
Soft actor-critic instead fixes a **target entropy** $\bar{\mathcal H}$ and treats $\alpha$ as a Lagrange multiplier.

The constrained problem is to maximize return while keeping the average entropy above the target:

$$
\max_\pi\; \mathbb{E}_\pi\left[\sum_t \gamma^t R_t\right] \quad \text{subject to} \quad \mathbb{E}_{s}\Big[\mathcal{H}\big(\pi(\cdot \mid s)\big)\Big] \ge \bar{\mathcal H}.
$$

This is the same structure as the [constrained Markov decision process](/notes/reinforcement-learning/reward-functions/) in reward functions,
and $\alpha$ plays the role of $\lambda$.
The policy update optimizes the Lagrangian for the current $\alpha$.
The multiplier is updated by minimizing

$$
J(\alpha) = \mathbb{E}_{s \sim \mathcal{D},\, a \sim \pi_\theta}\Big[-\alpha\big(\log \pi_\theta(a \mid s) + \bar{\mathcal H}\big)\Big].
$$

Its gradient is

$$
\frac{\partial J}{\partial \alpha} = \mathbb{E}\big[-\log \pi_\theta(a \mid s)\big] - \bar{\mathcal H} = \mathcal{H} - \bar{\mathcal H}.
$$

Gradient descent therefore does the obvious thing.
If the policy is more random than the target, $\alpha$ decreases and reward counts for more.
If it is less random, $\alpha$ increases and the policy is pushed to explore.
Implementations optimize $\log \alpha$ instead of $\alpha$, so that $\alpha$ stays positive,
and write the loss as $-\log \alpha\, \big(\log \pi_\theta + \bar{\mathcal H}\big)$.
The gradient has the same sign, so the behavior is the same.

The default target for an $m$-dimensional continuous action is $\bar{\mathcal H} = -m$.
A negative entropy is not an error.
Differential entropy is negative for narrow distributions (see [useful definitions](/notes/reinforcement-learning/useful-definitions/)),
and $-m$ corresponds to a moderately narrow policy.
For discrete actions, a fraction of the maximum, such as $0.6 \log |\mathcal{A}|$ or less, is typical.

## The algorithm

Initialize $\theta$, $\phi_1$, $\phi_2$, set $\bar\phi_j \leftarrow \phi_j$, and set $\log \alpha = 0$.
Fill $\mathcal{D}$ with a few thousand steps of uniformly random actions.
Then for each environment step:

1. **Act.** Sample $a \sim \pi_\theta(\cdot \mid s)$, step the environment,
   and store $(s, a, R, s', d)$ in $\mathcal{D}$.
2. **Sample.** Draw a minibatch from $\mathcal{D}$.
3. **Critic step.** Compute $y$ with fresh $\tilde a'$ and the target networks.
   Take one gradient step on $J_Q(\phi_1)$ and $J_Q(\phi_2)$.
4. **Actor step.** Sample fresh reparameterized actions at the minibatch states.
   Take one gradient step on $J_\pi(\theta)$, with the critics held fixed.
5. **Temperature step.** Take one gradient step on $J(\alpha)$, using the log-probabilities from step 4.
6. **Target update.** $\bar\phi_j \leftarrow \tau \phi_j + (1-\tau)\bar\phi_j$.

For evaluation, use the deterministic action $\tanh\big(\mu_\theta(s)\big)$.

The losses and the squashed sample in PyTorch:

```python
def sample(actor, obs):
    mu, log_std = actor(obs).chunk(2, dim=-1)
    std = log_std.clamp(-20, 2).exp()
    u = mu + std * torch.randn_like(mu)
    log_jac = 2 * (math.log(2) - u - F.softplus(-2 * u))
    logp = Normal(mu, std).log_prob(u).sum(-1) - log_jac.sum(-1)
    return torch.tanh(u), logp


def critic_loss(actor, q1, q2, q1_targ, q2_targ, log_alpha, b, gamma=0.99):
    with torch.no_grad():
        a2, logp2 = sample(actor, b.next_obs)
        q_next = torch.min(q1_targ(b.next_obs, a2), q2_targ(b.next_obs, a2))
        y = b.rew + gamma * (1 - b.terminated) * (q_next - log_alpha.exp() * logp2)
    return (q1(b.obs, b.act) - y).pow(2).mean() + (q2(b.obs, b.act) - y).pow(2).mean()


def actor_and_alpha_loss(actor, q1, q2, log_alpha, b, target_entropy):
    a, logp = sample(actor, b.obs)
    q = torch.min(q1(b.obs, a), q2(b.obs, a))
    actor_loss = (log_alpha.exp().detach() * logp - q).mean()
    alpha_loss = -(log_alpha * (logp.detach() + target_entropy)).mean()
    return actor_loss, alpha_loss
```

Each loss has its own optimizer.
The actor loss backpropagates through the critics,
so step only the actor's parameters with it and zero the critics' gradients before their next step.

## Typical hyperparameters

| Parameter | Typical value |
| --- | --- |
| Discount $\gamma$ | $0.99$ |
| Learning rate (actor, critics, $\alpha$) | $3 \times 10^{-4}$ |
| Minibatch size | $256$ |
| Replay buffer size | $10^6$ |
| Polyak coefficient $\tau$ | $0.005$ |
| Target entropy $\bar{\mathcal H}$ | $-\dim(\mathcal{A})$ |
| Random warm-up steps | $5000$ to $10^4$ |
| Gradient steps per environment step | $1$ |

## Soft actor-critic and proximal policy optimization side by side

| | Proximal policy optimization | Soft actor-critic |
| --- | --- | --- |
| Data | On-policy, discarded after each update | Off-policy, replay buffer |
| Critic | $V_\phi(s)$ | Two $Q_\phi(s, a)$ plus target networks |
| Policy gradient | Score function, $\nabla_\theta \log \pi_\theta \cdot \hat A_t$ | Reparameterized, through $\nabla_a Q$ |
| Keeps updates safe by | Clipping the probability ratio | Small steps, target networks, clipped double Q |
| Exploration | Gaussian noise with a learned, state-independent $\sigma$ | Entropy in the objective, state-dependent $\sigma$, automatic $\alpha$ |
| Action spaces | Discrete and continuous | Mainly continuous |
| Sample efficiency | Low | High |
| Scales with parallel simulation | Very well | Less well; limited by gradient steps per sample |
| Sensitivity | Robust to hyperparameters | More sensitive, especially to reward scale without auto-$\alpha$ |

A rough rule: if environment steps are cheap and you can run thousands of simulators in parallel,
use proximal policy optimization.
If environment steps are expensive, as on real hardware or with slow simulators, use soft actor-critic.
