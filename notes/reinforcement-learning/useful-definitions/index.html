Useful definitions

Updated November 16, 2026

This page collects useful definitions and terms commonly used in reinforcement learning literature, written with assistance from Claude.

1. The problem

Markov decision process

A Markov decision process (MDP) is the tuple M=(S,A,P,R,ρ0,γ)\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, R, \rho_0, \gamma)M=(S,A,P,R,ρ0​,γ):

  • S\mathcal{S}S is the state space. A state s∈Ss \in \mathcal{S}s∈S is everything the agent needs to know about the world to predict what happens next.
  • A\mathcal{A}A is the action space. An action a∈Aa \in \mathcal{A}a∈A is what the agent chooses. It is discrete if it is a finite set (left, right, fire) and continuous if it is a subset of Rm\mathbb{R}^mRm (motor torques).
  • P(s′∣s,a)P(s' \mid s, a)P(s′∣s,a) is the transition kernel: the probability (or density) of landing in s′s's′ after taking aaa in sss.
  • R(s,a,s′)R(s, a, s')R(s,a,s′) is the reward function. It returns a scalar. We write RtR_tRt​ for the reward received at step ttt.
  • ρ0(s)\rho_0(s)ρ0​(s) is the initial state distribution.
  • γ∈[0,1)\gamma \in [0, 1)γ∈[0,1) is the discount factor. It makes a reward kkk steps in the future worth γk\gamma^kγk times a reward now.
In other sources

The tuple is often shortened to (S,A,P,R,γ)(\mathcal{S}, \mathcal{A}, P, R, \gamma)(S,A,P,R,γ). The transition kernel is also written T(s′∣s,a)T(s' \mid s, a)T(s′∣s,a), p(s′∣s,a)p(s' \mid s, a)p(s′∣s,a) or Pss′a\mathcal{P}^a_{ss'}Pss′a​, and called the dynamics or transition function. The reward function is also written r(s,a)r(s, a)r(s,a) or R(s,a)\mathcal{R}(s, a)R(s,a), often without s′s's′. The initial distribution is also μ\muμ, d0d_0d0​ or p0p_0p0​. In control texts, the state is xxx and the action is uuu, and reward is replaced by a cost ccc or ℓ\ellℓ to be minimized.

The word Markov means that PPP and RRR depend only on the current sss and aaa, not on the history before them. If the agent only sees an observation ooo that does not contain the full state, the problem is a partially observable Markov decision process (POMDP).

Steps, episodes, trajectories

At each time step ttt, the agent sees sts_tst​, picks ata_tat​, and the environment returns RtR_tRt​ and st+1∼P(⋅∣st,at)s_{t+1} \sim P(\cdot \mid s_t, a_t)st+1​∼P(⋅∣st​,at​).

A trajectory is the sequence

τ=(s0,a0,R0,s1,a1,R1,…).\tau = (s_0, a_0, R_0, s_1, a_1, R_1, \ldots).τ=(s0​,a0​,R0​,s1​,a1​,R1​,…).
In other sources

Rollout, path, or (for a complete one) episode.

An episode is a trajectory that ends at a terminal state, after TTT steps. Tasks with episodes are episodic. Tasks that never end are continuing.

In other sources

TTT is also written HHH and called the horizon. A finite-horizon Markov decision process has a fixed HHH and often no discount.

Episodes typically end for one of two reasons:

  • Termination: the Markov decision process itself reaches a terminal state (the robot fell over, the goal was reached). No future reward exists after this state.
  • Truncation: we stopped the episode for some reason, such as a time limit. The Markov decision process did not end, so future reward still exists.
In other sources

Papers usually write a termination flag dtd_tdt​ or donet\text{done}_tdonet​, equal to 111 at a terminal state.

Reward, return and value

Three quantities are easy to confuse:

  • The reward RtR_tRt​ is the signal from one step. It says how good the last transition was.
  • The return GtG_tGt​ is the discounted sum of all rewards from step ttt on, in one particular trajectory. It is a random variable.
  • The value Vπ(s)V^\pi(s)Vπ(s) is the expected return. It averages the return over every way the future can unfold. (and is defined in the next section)

The return is

Gt=∑k=0∞γkRt+k=Rt+γGt+1.G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k} = R_t + \gamma G_{t+1}.Gt​=k=0∑∞​γkRt+k​=Rt​+γGt+1​.

The second form is the recursion that most of reinforcement learning is built on. The effective horizon is about 1/(1−γ)1/(1-\gamma)1/(1−γ) steps.

In other sources

The return is written GtG_tGt​ (Sutton and Barto), RtR_tRt​ (older papers, where it clashes with the reward), R(τ)R(\tau)R(τ) for a whole trajectory, and R^t\hat R_tR^t​ when it is an estimate. It is also called the reward-to-go, cumulative reward or discounted return. The undiscounted sum is the episode return, which is what training curves usually plot, even when the algorithm optimizes the discounted one.

Policy

A policy chooses actions.

  • A stochastic policy π(a∣s)\pi(a \mid s)π(a∣s) is a probability distribution over actions for each state.
  • A deterministic policy μ(s)\mu(s)μ(s) returns one action.
  • A parameterized policy πθ\pi_\thetaπθ​ has parameters θ\thetaθ, usually the weights of a neural network. For discrete actions the network outputs logits and a softmax turns them into probabilities. For continuous actions it usually outputs the mean μθ(s)\mu_\theta(s)μθ​(s) and standard deviation σθ(s)\sigma_\theta(s)σθ​(s) of a Gaussian.

2. Value functions

State value and action value

The state-value function is the expected return when we start in sss and follow π\piπ:

Vπ(s)=Eπ[Gt∣st=s].V^\pi(s) = \mathbb{E}_\pi\big[G_t \mid s_t = s\big].Vπ(s)=Eπ​[Gt​∣st​=s].

The action-value function (or Q-function) is the expected return when we start in sss, take aaa first, and follow π\piπ after:

Qπ(s,a)=Eπ[Gt∣st=s, at=a].Q^\pi(s, a) = \mathbb{E}_\pi\big[G_t \mid s_t = s,\, a_t = a\big].Qπ(s,a)=Eπ​[Gt​∣st​=s,at​=a].

They are related by averaging over the policy’s action: Vπ(s)=Ea∼π(⋅∣s)[Qπ(s,a)]V^\pi(s) = \mathbb{E}_{a \sim \pi(\cdot \mid s)}\big[Q^\pi(s, a)\big]Vπ(s)=Ea∼π(⋅∣s)​[Qπ(s,a)].

In other sources

The learned approximations are VϕV_\phiVϕ​, v^(s,w)\hat v(s, \mathbf{w})v^(s,w) (Sutton and Barto), QθQ_\thetaQθ​ or Q(s,a;θ)Q(s, a; \theta)Q(s,a;θ). The state value is often just called the value, and QQQ the state-action value or quality. A network that learns either one is a critic, and in proximal policy optimization code it is the value head.

Advantage

The advantage says how much better aaa is than the policy’s average action in sss:

Aπ(s,a)=Qπ(s,a)−Vπ(s).A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s).Aπ(s,a)=Qπ(s,a)−Vπ(s).

3. Learning value functions

Bootstrapping and targets

To fit an estimate VϕV_\phiVϕ​ (a network with parameters ϕ\phiϕ), we regress it onto a target. Two kinds of target exist:

  • Monte Carlo (MC): use the observed return GtG_tGt​. It is unbiased but has high variance, since it adds up the randomness of every future step.
  • Temporal difference (TD): use Rt+γVϕ(st+1)R_t + \gamma V_\phi(s_{t+1})Rt​+γVϕ​(st+1​). It uses our own estimate of the future in place of the real future. This is called bootstrapping. It has low variance but it is biased while VϕV_\phiVϕ​ is wrong.

Temporal-difference error

The temporal-difference error is used to evaluate the consistency of the learned value function and is expressed as:

δt=Rt+γV(st+1)−V(st).\delta_t = R_t + \gamma V(s_{t+1}) - V(s_t).δt​=Rt​+γV(st+1​)−V(st​).

If V=VπV = V^\piV=Vπ, then E[δt∣st,at]=Aπ(st,at)\mathbb{E}[\delta_t \mid s_t, a_t] = A^\pi(s_t, a_t)E[δt​∣st​,at​]=Aπ(st​,at​). So δt\delta_tδt​ is a one-step, one-sample estimate of the advantage.

In other sources

temporal-difference residual (the generalized advantage estimation paper, written δtV\delta_t^VδtV​), one-step advantage, or Bellman error of a single sample.

nnn-step returns

Between the two extremes, the nnn-step return uses nnn real rewards and then bootstraps:

Gt(n)=Rt+γRt+1+⋯+γn−1Rt+n−1+γnV(st+n).G_t^{(n)} = R_t + \gamma R_{t+1} + \cdots + \gamma^{n-1} R_{t+n-1} + \gamma^n V(s_{t+n}).Gt(n)​=Rt​+γRt+1​+⋯+γn−1Rt+n−1​+γnV(st+n​).

Target networks

A target network ϕˉ\bar\phiϕˉ​ is a slow copy of ϕ\phiϕ used only inside the target R+γQϕˉ(s′,a′)R + \gamma Q_{\bar\phi}(s', a')R+γQϕˉ​​(s′,a′). Without it, every gradient step moves the target it chases. It is updated either by periodic copying or by Polyak averaging, ϕˉ←τϕ+(1−τ)ϕˉ\bar\phi \leftarrow \tau \phi + (1-\tau)\bar\phiϕˉ​←τϕ+(1−τ)ϕˉ​ with small τ\tauτ such as 0.0050.0050.005.

Overestimation bias

If QQQ estimates are noisy, then max⁡aQ(s,a)\max_a Q(s, a)maxa​Q(s,a) is biased upward, since the max picks whichever action happened to have the largest positive error. Because the target bootstraps on this max, the bias compounds through the Bellman recursion.

The deadly triad

Function approximation, bootstrapping and off-policy data are each useful. Combined, they can make value learning diverge. Target networks, double Q-learning and conservative updates exist to keep this combination stable.

4. Families of algorithms

Model-free and model-based

A model-based method learns or is given PPP and RRR, and plans or generates synthetic data with them. A model-free method learns a policy or value function directly from transitions without a model. Proximal policy optimization and soft actor-critic are both model-free.

In other sources

A learned model is a world model or dynamics model, written P^\hat PP^, T^\hat TT^ or fψf_\psifψ​.

Value-based, policy-based, actor-critic

  • Value-based methods learn QQQ and act greedily with respect to it (deep Q-networks, or DQN). They suit discrete actions, because arg⁡max⁡a\arg\max_aargmaxa​ over a continuous space is itself an optimization.
  • Policy-based methods (or policy gradient methods) adjust πθ\pi_\thetaπθ​ directly in the direction that increases JJJ (REINFORCE).
  • Actor-critic methods do both. The actor is the policy πθ\pi_\thetaπθ​, while the critic is a learned value function VϕV_\phiVϕ​ or QϕQ_\phiQϕ​ that reduces the variance of the actor’s update. Proximal policy optimization and soft actor-critic are both actor-critic.
In other sources

Value-based methods are also called Q-learning methods or, for exact tabular versions, dynamic programming (value iteration, policy iteration). Policy-based methods are also called policy search or policy optimization.

Policy gradient

The policy gradient theorem gives the gradient of JJJ without differentiating through the environment:

∇θJ(πθ)=Eτ∼πθ[∑tγt ∇θlog⁡πθ(at∣st) Aπθ(st,at)].\nabla_\theta J(\pi_\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\left[\sum_{t} \gamma^t\, \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, A^{\pi_\theta}(s_t, a_t)\right].∇θ​J(πθ​)=Eτ∼πθ​​[t∑​γt∇θ​logπθ​(at​∣st​)Aπθ​(st​,at​)].

The term ∇θlog⁡πθ(a∣s)\nabla_\theta \log \pi_\theta(a \mid s)∇θ​logπθ​(a∣s) is the score function. It is the direction in parameter space that makes aaa more likely in sss. The gradient pushes up the log-probability of actions with positive advantage and pushes down those with negative advantage. In practice, the γt\gamma^tγt factor is usually dropped, which gives a slightly biased but better-behaved estimator.

The key identity behind it is the log-derivative trick: ∇θpθ(x)=pθ(x)∇θlog⁡pθ(x)\nabla_\theta p_\theta(x) = p_\theta(x) \nabla_\theta \log p_\theta(x)∇θ​pθ​(x)=pθ​(x)∇θ​logpθ​(x). It turns the gradient of an expectation into an expectation we can sample.

Reparameterization gradient

A second way to differentiate an expectation over actions exists when the action can be written as a differentiable function of noise: a=fθ(s,ξ)a = f_\theta(s, \xi)a=fθ​(s,ξ) with ξ∼N(0,I)\xi \sim \mathcal{N}(0, I)ξ∼N(0,I). Then

∇θ Ea∼πθ[Q(s,a)]=Eξ[∇aQ(s,a) ∇θfθ(s,ξ)].\nabla_\theta\, \mathbb{E}_{a \sim \pi_\theta}\big[Q(s, a)\big] = \mathbb{E}_{\xi}\big[\nabla_a Q(s, a)\, \nabla_\theta f_\theta(s, \xi)\big].∇θ​Ea∼πθ​​[Q(s,a)]=Eξ​[∇a​Q(s,a)∇θ​fθ​(s,ξ)].

This uses the gradient of QQQ with respect to the action, so it needs a differentiable critic and continuous actions. It usually has much lower variance than the score-function form. Soft actor-critic uses it.

5. Training

Behavior and target policy

The behavior policy β\betaβ is the policy that collected the data. The target policy π\piπ is the policy we are evaluating or improving.

In other sources

The behavior policy is written bbb (Sutton and Barto), μ\muμ or πβ\pi_\betaπβ​. It is also called the data-collection, logging or rollout policy. “Target policy” has nothing to do with target networks.

On-policy

An on-policy method uses data only from the current policy: β=π\beta = \piβ=π. After each update the old data no longer comes from the current policy, so it is thrown away. On-policy methods (REINFORCE, advantage actor-critic, trust region policy optimization, proximal policy optimization) are usually stable and simple to reason about, but sample inefficient since each transition is used for only a few gradient steps.

Off-policy

An off-policy method can learn about π\piπ from data collected by any β\betaβ, including old versions of π\piπ, other agents, or humans. It stores transitions in a replay buffer D\mathcal{D}D and samples minibatches from it many times. Off-policy methods (deep Q-networks, soft actor-critic) are much more sample efficient, but more sensitive to hyperparameters and to the deadly triad.

What makes a method off-policy is the form of its update. Q-function targets (see the Bellman equation above) only need (s,a,R,s′)(s, a, R, s')(s,a,R,s′) and a fresh a′a'a′ from the current policy, so they are valid on any transition. The policy gradient is an expectation over states and actions from π\piπ, so it is on-policy unless corrected.

In other sources

The replay buffer is also written B\mathcal{B}B or R\mathcal{R}R, and called experience replay or replay memory. A transition (s,a,R,s′,d)(s, a, R, s', d)(s,a,R,s′,d) is also called an experience or sample, and the tuple is often written (s,a,r,s′)(s, a, r, s')(s,a,r,s′).

Importance sampling

Importance sampling reweights samples from one distribution to estimate an expectation under another:

Ex∼p[f(x)]=Ex∼q[p(x)q(x)f(x)].\mathbb{E}_{x \sim p}\big[f(x)\big] = \mathbb{E}_{x \sim q}\left[\frac{p(x)}{q(x)} f(x)\right].Ex∼p​[f(x)]=Ex∼q​[q(x)p(x)​f(x)].

For actions, the importance ratio is π(a∣s)/β(a∣s)\pi(a \mid s) / \beta(a \mid s)π(a∣s)/β(a∣s). It is unbiased but its variance grows fast as π\piπ and β\betaβ separate, and ratios over many steps multiply. Proximal policy optimization uses a single-step ratio and keeps π\piπ close to β\betaβ so the ratio stays near one.

Online and offline

Online reinforcement learning interacts with the environment while it learns. Offline reinforcement learning learns from a fixed dataset and never interacts. Offline reinforcement learning is off-policy by necessity, with the extra problem that it can never collect data to check actions the dataset does not contain.

Training Efficiency

Sample efficiency counts environment steps needed to reach a given performance. It matters most when steps are expensive, such as on a real robot. When a fast simulator can run thousands of environments in parallel, wall-clock time often matters more, and on-policy methods can be competitive or better.

6. Exploration

Exploration and exploitation

Exploitation picks the action currently believed best. Exploration picks other actions to learn whether they are better. Too little exploration converges to a poor local optimum that may not generalize well, which too much exploration is sample inefficient.

Common methods

  • ϵ\epsilonϵ-greedy: with probability ϵ\epsilonϵ take a random action, otherwise the greedy one. Used with discrete value-based methods.
  • Stochastic policies: sampling from πθ\pi_\thetaπθ​ explores by itself. Its randomness shrinks as training sharpens the policy, sometimes too early.
  • Entropy regularization: add a bonus for policy randomness to the objective, so the policy stays stochastic until there is a reason to commit.

Entropy

The entropy of a policy at state sss measures its randomness:

H(π(⋅∣s))=Ea∼π(⋅∣s)[−log⁡π(a∣s)].\mathcal{H}\big(\pi(\cdot \mid s)\big) = \mathbb{E}_{a \sim \pi(\cdot \mid s)}\big[-\log \pi(a \mid s)\big].H(π(⋅∣s))=Ea∼π(⋅∣s)​[−logπ(a∣s)].

For nnn discrete actions it ranges from 000 (deterministic) to log⁡n\log nlogn (uniform). For continuous actions it is a differential entropy, which can be negative. A one-dimensional Gaussian has H=12log⁡(2πeσ2)\mathcal{H} = \tfrac12 \log(2\pi e \sigma^2)H=21​log(2πeσ2), which is negative when σ<0.242\sigma \lt 0.242σ<0.242.

7. Measuring distance between policies

Kullback-Leibler divergence

The Kullback-Leibler divergence between two distributions is

DKL(p ∥ q)=Ex∼p[log⁡p(x)q(x)]≥0,D_{\mathrm{KL}}(p \,\|\, q) = \mathbb{E}_{x \sim p}\left[\log \frac{p(x)}{q(x)}\right] \geq 0,DKL​(p∥q)=Ex∼p​[logq(x)p(x)​]≥0,

with equality only when p=qp = qp=q, and is not symmetric. Between policies it is computed per state and averaged over visited states:
Es[DKL(πold(⋅∣s) ∥ π(⋅∣s))]\mathbb{E}_{s}\big[D_{\mathrm{KL}}\big(\pi_{\text{old}}(\cdot \mid s) \,\|\, \pi(\cdot \mid s)\big)\big]Es​[DKL​(πold​(⋅∣s)∥π(⋅∣s))].

Trust region

A trust region is a neighborhood of the current policy, usually defined by a Kullback-Leibler divergence bound, within which a local approximation of JJJ is accurate. Limiting each update to this region prevents one bad step from destroying the policy.
