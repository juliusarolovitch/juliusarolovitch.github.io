First-order filters

Updated November 14, 2026

The role of a filter is to shape a signal waveform into one that is more desired, frequently by attenuating high or low frequency components. Filters act very analogously to controllers and estimators, in that they map an input onto an output, and are frequently analyzed in similar ways.

To begin our study of filters, we start with the first-order filter.

Filter order

The order of a filter can be defined in several equivalent ways, but a useful intuition is that it equals the number of internal states required to describe the system. In physical systems, this often corresponds to the number of independent energy storage elements (such as capacitors, inductors, masses, or springs). The higher the order, the more complex the dynamics (or ability to shape the signal) that the filter has. See system order for an elaborated explanation.

Continuous-time filters

Consider a signal we’d like to filter. Intuitively, we view a filtered version of a signal as one that’s more smooth than the original signal. To formalize this, consider a signal uuu and filtered version of the signal yyy (the filter output). We can define a simple filter as such:

dydt=a(u−y)\frac{dy}{dt}=a(u-y)dtdy​=a(u−y)

Here, we see that the rate of change of the output yyy is proportional to the difference between the unfiltered and filtered signal. The higher aaa is, the greater the corrections will be to the output and the more it will resemble the input signal. The lower aaa is, the smaller the corrections will be to the output and the more sluggish the corrections to the output will be, leading the output to appear ‘more filtered’ to the human eye.

We typically reformulate aaa into 1τ\frac{1}{\tau}τ1​ where τ\tauτ is called the time constant.

dydt=1τ(u−y)\frac{dy}{dt}=\frac{1}{\tau}(u-y)dtdy​=τ1​(u−y)

For a step input u(t)u(t)u(t), y(t)=1−e−t/τy(t)=1-e^{-t/\tau}y(t)=1−e−t/τ. We see that the filtered signal exponentially approaches the input.

Discrete-time filters

The discrete time (DT) version of the first-order filter may feel even more familiar. A typical way of notating it is as follows:

y[k]=(1−α)y[k−1]+αu[k]y[k]=(1-\alpha)y[k-1]+\alpha u[k]y[k]=(1−α)y[k−1]+αu[k]

Here, α\alphaα parametrizes the filter, and has the inverse function of its CT-analog τ\tauτ. In the formulation of the filter, we see that the output is equal to 1−α1-\alpha1−α times its output at the previous timestep, plus a sample of the current value of the input signal (scaled by α\alphaα). This way, we are incorporating a small bit of the current value of the signal at each time step.

If α=1\alpha=1α=1, then the filtered signal tracks the input exactly. If α=0\alpha=0α=0, then the filtered signal is latched and entirely disregards the input.

The response of the DT first-order filter to a step input u[k]u[k]u[k] is given by:

y[k]=1−(1−α)ky[k]=1-(1-\alpha)^ky[k]=1−(1−α)k

As you can see, like its CT analog, the DT first-order filter exponentially approaches the input. In fact, the filter we have just learned is referred to as the Exponential Moving Average (EMA) filter.
